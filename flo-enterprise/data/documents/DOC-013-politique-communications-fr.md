# Approbation des communications
Les communications aux clients portant sur le rendement ou les produits doivent être approuvées par la conformité avant l'envoi. Les communications rédigées avec l'aide de l'IA doivent être approuvées par un agent de conformité.

# Contenu interdit
Les communications ne doivent pas garantir de rendement ni présenter des projections comme certaines.
