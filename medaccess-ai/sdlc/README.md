# SDLC artifacts

Generated by the platform's own SDLC agents (not hand-written). Regenerate with:

```bash
cd backend && python -m app.sdlc_engine.export
```

* `requirements/` Requirements Agent analysis of the 90-Day MRI requirement
* `architecture/` Mermaid diagrams (patient and SDLC graphs rendered from the compiled LangGraphs)
* `qa/` scenario-suite reports for builds 1.4.0 (baseline), 1.5.0 (controlled defect) and 1.5.1 (fix);
  `make test` also writes `qa/pytest-report.xml` (git-ignored)
* `development/` proposed fix for the defect
* `monitoring/` RCA evidence for build 1.5.0

Per-run artifacts of the interactive demo are stored in the `sdlc_artifacts` table and exposed at
`/api/v1/sdlc/demo/{run_id}/traceability`. `releases/` and `security/` are populated at runtime via the API.
