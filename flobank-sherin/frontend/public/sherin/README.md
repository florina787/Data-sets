# Sherin's approved portrait

Place the previously approved Ghibli-style image of Sherin here as **`sherin-ghibli.png`**.

Every screen loads this one file through the `SherinAvatar` component (`src/components/SherinAvatar.tsx`).
No other face is generated or substituted: until the file is present, the component shows a neutral
leaf monogram and a "portrait pending" tooltip.
