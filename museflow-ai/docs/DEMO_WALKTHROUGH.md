# MuseFlow AI — 5-minute demo walkthrough

1. **Dream Dashboard** — point out the *PUBLIC DEMO · SIMULATED AI* badge and the KPI tags
   (*measured* vs *illustrative estimate*). Press **✨ Start the Magic**.
2. **Lumi AI Chat** — the dream-team request runs immediately. Read the numbered activation list:
   each line is an executed LangGraph node. Rosie proposed a simulated email, so the run is
   **Pending approval**. Expand *Inspect the exact simulated action*, then **💖 Approve**.
3. Click **🔮 Open in Workflow Galaxy** — violet edges are the path actually taken; the
   supervisor's dashed conditional edges fan out to each specialist. Switch to *Timeline* for
   measured durations, then use the **Node inspector** to show a node's input and output.
4. **Browser Magic** → *Complete a simulated online booking* → **Run**. The timeline shows a
   simulated page-load timeout and an automatic retry before approval is requested. Reject it in
   the **Human Approval Center** and show that no booking was created.
5. **Email Boutique** — generate a draft, edit it, press **🔁 Apply my edits** (the old pending run
   is cancelled and a new one is governed), then **📨 Simulate Send**. The *Simulated outbox* shows it.
6. **Memory Garden** — plant “I focus best in the afternoon”, then ask Lumi “Help me plan a
   productive week.” — deep-work blocks move to the afternoon.
7. **Celestial Calendar → Schedule a meeting** — choose Wednesday 10:00; Celeste detects the clash
   with the fictional client sync and proposes 11:00.
8. **Trust & Governance** — the live SDK check, allowlist, policy playground (try *Run a shell
   command*) and the hash-chained audit log (`verified=True`).
9. **Magic Analytics** and **Achievement Garden** — everything reflects what you just did.
10. **Settings** — switch to *Midnight Mermaid*, turn on reduced motion.
