# Project Moonbeam — Requirements (SYNTHETIC SAMPLE)

Owner: Demo Dreamer
Status: Draft
Target Launch: 2026-12-01
Budget: $85,000

## Goal

Project Moonbeam will deliver a personal planning assistant that helps users organise their week. The assistant must explain every action it takes and ask before doing anything consequential.

## Functional Requirements

- FR-1: Users can add, edit and delete personal preferences.
- FR-2: The assistant proposes a weekly plan using calendar availability.
- FR-3: Every consequential action requires explicit user approval.
- FR-4: Users can view an execution trace for each workflow.

## Non-Functional Requirements

- NFR-1: Page interactions should respond within 300 milliseconds.
- NFR-2: All user input must be validated and escaped before display.
- NFR-3: The system must work without third-party API keys in demo mode.

## Milestones

- Milestone 1: Workflow graph prototype — 2026-10-15
- Milestone 2: Approval checkpoints — 2026-11-01
- Milestone 3: Analytics and launch readiness — 2026-11-20

## Acceptance Criteria

The project is accepted when all functional requirements pass automated tests and a security review finds no high-severity issues.
