* **Credits do not expire** (owner to confirm; non-expiry also avoids provincial gift-card / prepaid-purchase expiry rules, which you should still have reviewed).

* **Free trial:** three successful uses of each feature per person. We count trial uses per account **and** per installation. Creating extra accounts to obtain more trials is not allowed; an installation used by several accounts may lose trial eligibility. If this affects you unfairly (for example a shared family computer), appeal from the app.
* **Unlimited:** no usage quota on verified features. We may contact you, and if necessary suspend access after notice, only for automated or abusive use that harms the Service (for example scripted operation floods). Normal personal use is never limited.
* **Rate limits** on sign-in codes and checkout protect everyone and are not usage quotas.
* We do not use invasive device fingerprinting. This means duplicate-trial prevention is best-effort, not guaranteed.
