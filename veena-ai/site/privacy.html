Privacy policy

Applies to the VEENA.AI desktop application and this website. Last updated 9 November 2026.

The short version

VEENA runs on your computer. It has no accounts and no telemetry, and it does not send your conversations, recordings, screens or documents to us or to any cloud AI service.

What stays on your computer

  • Conversations, meeting transcripts, interview practice and documents you add, stored in a local database in your user folder.
  • AI models and the AI runtime, stored in VEENA's own folder.
  • Microphone audio is transcribed on your computer and never saved as a recording. Screenshots are analysed in memory and never saved; detected secrets are masked first.

History older than 30 days is deleted automatically by default. You can change this, export a conversation, or delete all history in Settings. Uninstalling VEENA removes the application; your data folder can be deleted as described in the support guide.

When VEENA uses the internet

  • Setup downloads, only when you start them: the AI runtime from Ollama's official GitHub release, AI models from the Ollama model library, and the speech and document-search models from Hugging Face. These services see an ordinary download request (your IP address and the file requested), under their own privacy policies.
  • Update check, only if you allow it: once a day VEENA asks GitHub's public API for the latest release version. It sends no identifier and no usage data.

Nothing else is sent. After setup, chat, document answers, meeting notes and screen analysis work without an internet connection.

This website

This site is static and sets no cookies. Your browser asks GitHub's public API which installers are available, so the download buttons only appear for files that exist. The hosting provider keeps standard server logs under its own policy. We do not run analytics on this site.

Your responsibilities

Only capture meetings, calls or screens you are authorised to capture, and follow the laws and policies that apply to you, including telling other participants when that is required. VEENA is designed for open use, not covert assistance.

Contact

Questions or concerns: open an issue on GitHub.
