The first launch downloads the free local AI runtime and a model (1–4 GB), so it needs an internet connection and some disk space. After that, VEENA works on your computer, even offline.

Recorded from the real app with real local models and sample data. Model waits are shortened and long answers play faster. On the 4-core, CPU-only recording machine a full-screen summary took about 3 minutes to start and 7 to finish; a computer with a GPU is much faster.

The open-source story

Built openly.
Built thoughtfully.

VEENA began with a simple idea: powerful AI should be accessible without expensive cloud subscriptions.

Built with open-source technologies and local AI models, VEENA puts intelligence closer to the people using it. Its development puts privacy, transparency, practical usefulness and easy distribution first.

  • Electron
  • React
  • Python · FastAPI
  • Ollama
  • Qwen models
  • Whisper
  • FAISS
  • SQLite
  • GitHub Actions

Developed with free, open-source tools. Running it still uses your computer's power and disk, and the first setup downloads a few gigabytes.
