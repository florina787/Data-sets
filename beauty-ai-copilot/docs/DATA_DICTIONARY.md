# Data dictionary

All data is synthetic. No record represents a real person, image or brand.

## Dataset record (`data/synthetic/dataset_snapshot.json` → `dataset_records` + `dataset_consent_records`)

| Field | Type | Meaning |
|---|---|---|
| `sample_id` | string | `S-00001` … `S-01560`. Opaque ID; carries no identity |
| `split` | `validation` \| `test` | 10 validation + 120 held-out test per cell. Only `test` is evaluated |
| `tone_stratum` | `TS-1`…`TS-4` | **Synthetic evaluation attribute** assigned at fixture creation (GP-DEMO-1). Not an endorsed classification method; never inferred from a face |
| `lighting_category` | `daylight_neutral` \| `warm_indoor` \| `cool_fluorescent` | Declared capture lighting (SPEC-LIGHT-003 §1) |
| `device_category` | `DEV-T1` \| `DEV-T2` | Evaluation covers only these two; DEV-T3 appears only in simulated monitoring |
| `expected_shade_id` | `SH-01`…`SH-40` | Reference label (catalogue identifier, not a colour measurement) |
| `label_provenance` | string | `LP-DEMO-PANEL-01` (fictional panel); label validity not established |
| `consent_record_id` | string | Link to the consent record |
| `consent_status` | `granted` \| `withdrawn` | From the consent record |
| `permitted_use` | list | `evaluation`, optionally `model_training`; some are `marketing_preview` only (not evaluable) |
| `retention_until` | date | Records past this date are ineligible |
| `image_quality` | `pass` \| `fail` | Failing records are ineligible (SPEC-IQ-002 §3) |
| `grouping_protocol` | string | Must start with `GP-DEMO-1`, otherwise ineligible |
| `image_ref` | string | `synthetic://no-image/<id>`; no image payloads exist |
| `declared_eligible` | bool | Informational only. Eligibility is **recomputed** at evaluation time |

Eligibility on the test split: 1,352 of 1,440 records. Exclusions: consent withdrawn 28, evaluation not permitted 18,
retention expired 17, image quality 25. Each required cell has 108–116 eligible paired samples.

## Fixture predictions (`data/synthetic/predictions/<model>.json`)

`{sample_id: {"abstained": bool, "top3": [shade_id, shade_id, shade_id]}}`. They are generated by
`app/datagen/synthetic.py` from per-cell profiles (`models.json → fixture_profiles`): `p1` (top-1 probability), `p3`
(top-3 probability), `pa` (abstention probability) and `bias` (catalogue-ordinal offset of wrong answers). Draws use
common random numbers per sample, so comparisons are paired.

| Model | Role | Code revision | Lighting map | Fixture design |
|---|---|---|---|---|
| `shade-matcher-v2.3.0` | baseline (released) | REV-2.3.0 | lpm-v1 | — |
| `shade-matcher-v2.4.0-rc1` | candidate | REV-2.4.0-rc1 | lpm-v1 | Global warm compensation: warm gains, TS-3 × cool over-darkens, more abstention on TS-4 × warm |
| `shade-matcher-v2.4.0-rc2` | corrected candidate | REV-2.4.0-rc2 | **lpm-v2** (DEV-T3 warm → cool defect) | Warm-only gated compensation |

**Artifact digest** = SHA-256 over {predictions file digest, preprocessing, lighting map, catalogue version, code
revision}. It is recomputed at evaluation, approval and deploy time.

## Knowledge documents (`data/knowledge/*.md`)

Front matter: `doc_id`, `version`, `title`, `status` (approved/superseded/unreviewed), `effective_date`, `owner_role`,
`access` (`all` or a role list). Sections are `## §n Heading`. Every document is marked **DEMO DOCUMENT**.
