DEMO DOCUMENT — fictional catalogue rules for the fictional brand Maison Fictive.

## §1 Catalogue versions
The active catalogue is CAT-2026.1 with 40 shades (SH-01 to SH-40) in four families: Light, Medium, Tan, Deep.

## §2 Compatibility
A model version is compatible with a catalogue version only if every shade ID it can emit exists in that catalogue. Rollback targets must be compatible with the active catalogue.
