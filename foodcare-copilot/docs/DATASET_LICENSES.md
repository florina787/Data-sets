# Dataset licences

| Dataset (registry id) | Images | Source | Licence | Real or synthetic |
|---|---|---|---|---|
| `synthetic-potatoes@v1-20x1000` | 20 (240 potatoes) | Rendered by `backend/app/vision/synthetic.py` | Generated by this project; no third-party content | **Synthetic**: drawn ellipses on a plain background |

**No real, labelled potato or French-fries images exist in this repository or on the build machine.** Accuracy on real produce has therefore not been measured.

## Adding a real dataset
```bash
.venv/bin/python scripts/eval_vision.py --dataset path/to/folder --name farm-photos --version 1 \
  --license "<exact licence, e.g. CC-BY-4.0 or 'internal, owned by ...'>" --source "<who, where, when>"
```
* `folder/annotations.json` is COCO format: boxes as `[x, y, width, height]`, with an optional `"attributes": {"grade": "Good|Moderate|Not Good"}` per box.
* A licence and a source are **required**. The import is refused without them.
* Images are referenced by path and SHA-256, and re-verified on every use, so a changed file is detected.
* **Splits are made per acquisition group** (`batch` or `session` field, else the filename prefix), never per image.
* **Near-duplicate photos** (difference hash within 5 bits) are merged into one group before splitting, and a leakage check confirms there are zero cross-split duplicates.

## Checklist before using any public dataset
1. Read its licence. Commercial use allowed? Attribution required? Redistribution allowed?
2. Record the URL, version, date and licence in this file.
3. Check how the images were collected (consent, ownership) and how labels were defined.
4. Get approval before downloading anything large.
