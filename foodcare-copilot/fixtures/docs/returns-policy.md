# Returns and Cancellations Policy

## 1. Cancellation
An order cancelled before fulfilment is refunded in full. A free promotional unit attached to a cancelled order is restored to the customer, as if the order had never been placed.

## 2. Partial returns of promotional orders
When part of a multi-buy promotional order is returned, the refund is calculated from the promotion allocation recorded when the order was placed: the amount paid for the promotion group is spread across all units in the group, including free units. Refunds must never be recalculated from current prices.

## 3. Entitlement after partial returns
A partial return does not restore a promotional entitlement.

## 4. Unit selection
When several units of the same product are returned, units outside a promotion group are returned first, then the most recently purchased units.
